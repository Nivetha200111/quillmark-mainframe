# quillmark-mainframe

> **SYNTHETIC.** Quillmark Trust & Savings is a fictional bank invented for the [Diocle](https://github.com/Nivetha200111/Diocle) hackathon project (Meta Global AI Developer Hackathon, October 2026). Every program, job, layout, definition and record here was written for the project. Nothing is derived from any real system, employer, client or person.

A legacy estate in the shape banks actually hand over: an export of z/OS libraries, not a folder of `.cbl` files. Extension-less PDS members, cataloged procedures with symbolic parameters, DFSORT and IDCAMS cards, GDGs, a DB2 schema and DCLGEN, a CICS screen, an IMS database, operations REXX, an Easytrieve report, a scheduler flow, a runbook, and EBCDIC extracts with packed fields. See [DATASETS.md](DATASETS.md).

Diocle imports this repository by its link, works out which programs it can convert and prove, converts them with Meta's Muse Spark, proves each one against the original COBOL, and opens a pull request on [quillmark-java](https://github.com/Nivetha200111/quillmark-java). Programs that need a database, transaction or VSAM adapter (STMTGEN, ACCTINQ, CUSTMNT) are reported, not converted.
